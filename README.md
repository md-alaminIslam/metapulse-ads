# MetaPulse - Facebook Ads Calculator & Performance Intelligence Suite

ফেসবুক অ্যাডস ক্যাম্পেইন মেট্রিক্স ক্যালকুলেটর, ব্রেক-ইভেন ROAS সিমুলেটর, লাইভ পারফরম্যান্স অটো-ট্র্যাকার এবং ১-ক্লিকে ক্লায়েন্ট রিপোর্ট বিল্ডার।

## 🚀 GitHub থেকে সরাসরি লাইভ (GitHub Pages) করার সহজ নিয়ম:

এই প্রজেক্টটিতে **GitHub Actions অটোমেটিক ডেপ্লয়মেন্ট** সম্পূর্ণরূপে সেটআপ করা আছে। আপনি শুধু গিটহাবে পুশ করলেই ওয়েবসাইট লাইভ হয়ে যাবে।

### ধাপ ১: আপনার GitHub-এ নতুন একটি রিপোজিটরি তৈরি করুন
1. [GitHub](https://github.com)-এ লগইন করে **New repository**-তে ক্লিক করুন।
2. রিপোজিটরির নাম দিন (যেমন: `metapulse-ads` বা `facebook-ads-calculator`)।
3. **Public** সিলেক্ট করুন এবং Create repository চাপুন।

### ধাপ ২: আপনার কোড GitHub-এ পুশ করুন
আপনার কম্পিউটারের টার্মিনালে এই কমান্ডগুলো একে একে রান করুন:

```bash
git init
git add .
git commit -m "Initial release of MetaPulse Ads"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git push -u origin main
```
*(লক্ষ্য করুন: `<your-username>` এবং `<your-repo-name>` এর জায়গায় আপনার আসল গিটহাব ইউজারনেম ও রিপোজিটরির নাম বসান)*

### ধাপ ৩: GitHub Pages চালু করুন (মাত্র ২টি ক্লিক)
1. আপনার GitHub রিপোজিটরি পেজে যান।
2. উপরের মেনু থেকে **Settings** ট্যাবে ক্লিক করুন।
3. বামদিকের মেনু থেকে **Pages** অপশনে ক্লিক করুন।
4. **Build and deployment** সেকশনে:
   - **Source** ড্রপডাউন থেকে **`GitHub Actions`** নির্বাচন করুন।
5. ব্যস! আর কিছুই করতে হবে না।

GitHub Actions নিজে থেকেই কোড বিল্ড করে আপনার লাইভ ওয়েবসাইটটি পাবলিশ করে দেবে এই লিংকে:  
👉 `https://<your-username>.github.io/<your-repo-name>/`

## 📱 অটোমেটিক Android APK ডাউনলোড করার নিয়ম:

আপনার গিটহাব রিপোজিটরিতে কোড পুশ হওয়ার সাথে সাথে GitHub Actions ক্লাউডেই অ্যান্ড্রয়েড অ্যাপ কম্পাইল করে তৈরি করবে:

1. আপনার গিটহাব রিপোজিটরির **Actions** ট্যাবে ক্লিক করুন।
2. **Build Android APK** নামের ওয়ার্কফ্লোটিতে ক্লিক করুন।
3. বিল্ড শেষ হলে নিচে **Artifacts** সেকশনে **`MetaPulse-Ads-Android-APK`** দেখতে পাবেন।
4. সেটিতে ক্লিক করলেই সরাসরি আপনার ফোনে ইনস্টল করার উপযোগী আসল `.apk` ফাইল ডাউনলোড হয়ে যাবে!
